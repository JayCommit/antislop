# Security

This repository is instruction text. It does not ship a service, credentials, or its own runtime.

Report a vulnerability in this repository through GitHub private vulnerability reporting:

<https://github.com/JayCommit/antislop/security/advisories/new>

Do not open a public issue for an undisclosed vulnerability. This project does not publish a security email address.

If the concern is a bad code suggestion rather than a vulnerability in the repository, open a public issue and redact private code and credentials. See the bug report template.
